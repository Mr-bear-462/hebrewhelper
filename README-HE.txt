עוזר - מוד לשיחה בעברית במיינקראפט 26.3 (Fabric)
==================================================

מה זה?
------
מוד שמוסיף עוזר שמדבר בצ'אט. כותבים לו בעברית (או באנגלית) והוא מבצע:
יהלומים, ארמור עם קסמים, זימון יצורים, בנייה, יום/לילה, מזג אוויר,
מצב משחק, טלפורט, אפקטים, ריפוי ועוד. כתוב בצ'אט:  עוזר עזרה

חשוב לדעת (בכנות)
-----------------
* זה לא AI אמיתי. הוא מזהה מילים ומספרים בתוך המשפט, ולכן הוא מבין
  הרבה ניסוחים, אבל לא כל משפט. כשהוא לא מבין הוא אומר לך.
* את הלוגיקה בעברית בדקתי בפועל. את החיבור למיינקראפט עצמו לא יכולתי
  להריץ, כי אין לי מיינקראפט. אם משהו נכשל, תעתיק לי את השגיאה ואתקן.

חלק א: בניית הקובץ (בערך 15 דקות, פעם אחת)
-------------------------------------------
1. חלץ את ה-ZIP הזה לתיקייה.
2. היכנס ל-github.com עם המשתמש שלך.
3. למעלה מימין לחץ על + ואז New repository.
   שם: hebrewhelper    בחר Public    ואז Create repository.
4. בדף שנפתח לחץ על הקישור  "uploading an existing file".
5. גרור לתוך הדף את **כל התוכן** של התיקייה שחילצת (לא את התיקייה עצמה):
   התיקיות .github, gradle, src והקבצים build.gradle, gradlew וכו'.
   (במק: אם התיקייה .github לא נראית, לחץ Cmd+Shift+נקודה בתוך Finder.)
6. למטה לחץ Commit changes.
7. לחץ על הלשונית Actions. אם מופיע כפתור
   "I understand my workflows, go ahead and enable them" לחץ עליו.
   הבנייה מתחילה לבד וקורית 3 עד 6 דקות. סימן וי ירוק = הצליח.
8. לחץ על הריצה האחרונה, גלול למטה לחלק Artifacts, והורד את "Artifacts".
9. חלץ את ה-ZIP שירד. הקובץ שצריך:  hebrewhelper-1.0.0.jar
   (לא הקובץ שמסתיים ב-sources).
   אם יש X אדום: לחץ על השלב שנכשל, תעתיק את הטקסט האדום ותשלח לי.

חלק ב: התקנה במיינקראפט (בערך 5 דקות)
-------------------------------------
1. הורד את Fabric Installer מ-fabricmc.net/use/installer
   והתקן עבור גרסת המשחק 26.3. זה יוצר פרופיל חדש בלאנצ'ר.
2. הורד את Fabric API לגרסה 26.3 מ-modrinth.com/mod/fabric-api
3. פתח את תיקיית המשחק: Win+R, כתוב  %appdata%\.minecraft  ואנטר.
   אם אין שם תיקייה בשם mods, צור אותה.
4. שים בתוך mods את שני הקבצים: Fabric API וגם hebrewhelper-1.0.0.jar
5. פתח את הלאנצ'ר, בחר את הפרופיל fabric-loader-26.3 ולחץ Play.
6. צור עולם, ובצ'אט כתוב:  עוזר עזרה

איך מדברים אליו
---------------
* צריך להתחיל בשם שלו (עוזר). אחרי זה אפשר להמשיך לדבר בלי השם
  במשך 3 דקות.
* דוגמאות:
    עוזר תביא לי 10 יהלומים בבקשה
    תביא ארמור יהלום עם mending ו swift sneak 100
    תזמן 3 חזירים
    תבנה בית מזכוכית        (גם: מגדל, פירמידה, טירה, בריכה, פלטפורמה, קיר)
    שנה ללילה     /    תעשה גשם    /    מצב יצירתי
    קח אותי ל 100 70 -200
    מה המצב?     /    תרפא אותי     /    תן לי מהירות 5
* מספרים: אפשר ספרות (64) או מילים (עשרים ושלוש).
